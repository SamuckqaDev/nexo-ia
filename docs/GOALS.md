# Goals

## Main goal

Build a complete local AI assistant while studying and documenting, in depth, the components of a
modern AI system.

## Learning goals

- Understand how an application communicates with a local LLM.
- Learn about tokens, context, prompts, sampling, and streaming.
- Implement conversation persistence and context management.
- Build RAG with ingestion, retrieval, citations, and quality evaluation.
- Create local tools with predictable contracts and verifiable results.
- Understand and implement the Model Context Protocol (MCP).
- Build a Permission Engine based on risk, scope, and consent.
- Implement an agent loop with limits and repetition protection.
- Study memory, observability, security, and recoverable execution.
- Compare Nexo IA's decisions with lessons learned from Avento.

## Product goals

- Run locally by default.
- Preserve user data privacy.
- Allow models to be changed without rewriting assistant capabilities.
- Present sources, actions, permissions, and results clearly.
- Remain extensible without tightly coupling every component.

## Success criterion

Nexo IA succeeds when every feature can be demonstrated, tested, and explained—not merely when its
interface appears to work.
